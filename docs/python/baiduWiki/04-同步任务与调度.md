# 首页同步任务与调度（草案）

> 依据 `01`/`02`/`03` 观测整理；实现前仍须建服务 `plans/` 四件套并确认数据源为自建。

---

## 1. 任务列表

| 任务名 | 读源（自建） | 写目标 | 建议周期 | 对应首页块 |
| --- | --- | --- | --- | --- |
| `sync_statistic` | 词条/编辑统计表 | Redis + 可选落库快照 | 5–15 min | HomeStatistic |
| `sync_hot_lemmas` | 运营热搜配置/算法表 | Redis `home:hot` | 1–5 min | 搜索热搜 |
| `sync_home_modules` | CMS：热点/知识/特色/图解/用户卡 | Redis `home:modules` | 发布触发或 10–30 min | 多卡片 |
| `sync_history_today` | 历史事件表 | Redis `home:history:{mmdd}` | 每日预热 | 历史上的今天 |
| `sync_user_dynamic` | 动态流水 | Redis list（限长） | 1–5 min | HomeDynamic |
| `sync_topic_menu` | 导航配置 | Redis `home:menu` | 发布触发 | 专题菜单 |

聚合读取：`GET /api/home/aggregate` 只读 Redis，缺失则触发单次回源或返回降级空块。

---

## 2. 进程拆分（符合 AGENTS）

- API：`./run.sh`（FastAPI）  
- 同步 Worker：`./mq.sh`（队列或 cron + worker 进程）  
- 日志：`log/` + 统一 logger；任务成功/失败打点  

---

## 3. 失败策略

- 单模块失败不影响其他模块聚合（返回上次成功缓存）  
- 有限重试 + 错误码  
- 禁止同步任务 `panic`/打挂整进程
