# 百度百科等价产品 —— 开发背景

> 文档目录：`docs/python/baiduWiki`  
> 技术选型（已定）：**Vue3 前端 + FastAPI 后端**  
> 本期目标（已定）：① **等价搜索** ② **首页数据同步**  
> 对照站点：`https://baike.baidu.com/`（观测日期：2026-09-19）  
> 本文只讲**背景与问题定义**，不写实现细节；设计见后续 `design` / 服务内 `plans/`。

---

## 1. 为什么要做

百度百科是中文世界最常见的「词条型知识入口」：用户带着一个词进来，期望**快速命中权威释义**；没事刷首页时，又期望看到**热搜、热点解读、知识专题、社区动态**等内容流。

本工作空间（azyasaxi）要做一套 **Vue3 + FastAPI** 的百科向产品原型/服务，核心不是像素级抄站，而是：

1. **搜索体验等价**：输入 → 建议/纠错 → 结果列表 → 进入词条，链路清晰、延迟可接受。  
2. **首页可运营、可同步**：首页各内容块有稳定数据源与刷新策略，前后端契约清楚，能定时或手动同步。

同时练齐本仓库 `AGENTS.md` 约定：异步 IO、连接池、统一日志/错误码、`run.sh`、plans 四件套等。

## 2. 对照站点：首页在干什么（产品拆解）

首页不是一张静态海报，而是 **「搜索框 + 多模块内容墙」**。

### 2.1 全局能力

| 能力 | 用户感知 | 说明 |
| --- | --- | --- |
| 搜索入口 | 「进入词条 / 全站搜索」 | 首页中心动作；热搜词可一键带入 |
| 站点导航 | 历史上的今天、特色百科、知识专题、加入百科等 | 内容分发与运营入口 |
| 登录态 | 登录/注册、个人中心 | 影响「我的词条/任务」类模块，搜索本身可匿名 |

### 2.2 首页内容模块（观测）

基于页面文案与首页接口回包，首页至少包含这些**可独立同步**的业务块：

| 模块（产品名） | 用户看到什么 | 数据特征 |
| --- | --- | --- |
| 平台统计 | 词条数、编辑次数、编写人数等 | 少量数字，变化频但结构稳 |
| 热搜词条 | 今天/昨天热词 + 摘要 + 跳转 | 列表，强时效，常配涨跌趋势 |
| 热点/专题卡片 | 标题、作者、摘要、配图、链接 | 运营向内容流 |
| 冷知识 / 图解等知识块 | 主题 + 关联词条 | 专题聚合 |
| 秒懂/V百科等富媒体 | 短内容/视频向入口 | 偏 CMS |
| 用户卡片（校园团/蝌蚪团/专家等） | 团队介绍 + 优秀用户 | 社区向 |
| 用户动态 | 谁编辑了什么、参与了什么任务 | 时间线，高刷 |
| 历史上的今天 | 按日事件 | 按日期分片的静态/半静态 JSON |

> 结论：首页 = **搜索入口** + **多源内容聚合**。  
> 「首页数据同步」不是一个接口能搞定，而是**按模块定义同步任务**。

## 3. 对照站点：公开接口形态（观测，非正式文档）

首页加载时，浏览器会请求一组 XHR（2026-09-19 观测，路径可能变更）：

| 观测 URL | 作用（推断） | 对我们的启发 |
| --- | --- | --- |
| `GET /lemma/api/home/module` | 首页主模块聚合（特色、热搜、热点、知识、用户卡片等） | 自建可用「BFF 聚合接口」或分模块接口 |
| `GET /lemma/api/home/statistic` | 全站统计数字 | 适合缓存 + 短 TTL 同步 |
| `GET /lemma/api/home/dynamic` | 用户动态流 | 适合异步拉取、分页/限制条数 |
| `GET .../cms/home/hotLemmas.json` | CDN 上的热搜词条 JSON | 说明部分首页数据可走 **静态 CMS/对象存储** |
| `GET .../cms/home/eventsOnHistory/MM.json` | 「历史上的今天」按月分片 | 适合按日历预生成 |
| `GET .../cms/pc_index/knowledge_topic_menu.json` | 知识专题菜单 | 导航/菜单配置化 |
| `GET /api/wikihome/userlemma` | 与用户相关的词条 | 登录态模块，可二期 |
| 广告/风控类接口 | 与核心百科无关 | **自建产品不复制** |

`module` 回包大致结构（观测）：

```text
data
├── characteristics[]   # 特色入口
├── hotLemma[]          # 热搜（含 today/yesterday 语义）
├── hotspot[]           # 热点卡片
├── knowledge[]         # 知识块 + 关联 lemmas
├── photoBaike[]        # 图解/富媒体入口
├── userCard[]          # 社区团队卡片
└── style               # 展示样式（可空）
```

`statistic` 回包字段示例：`totalLemma`、`totalEditNum`、`totalEditUser`、`totalSchool` 等。

**重要合规说明**：上述 URL 仅用于理解「业界首页如何拆模块」。  
本项目默认定位为 **自建等价能力**（自有词条库 + 自有运营数据），**不默认、不鼓励**未经授权抓取、镜像百度百科正文或绕过其防护。若业务确需「同步外部公开数据」，必须单独做合规评审，并优先官方合作/授权数据源。

## 4. 需求一：等价搜索（背景）

### 4.1 用户要什么

「等价」指体验上接近百科搜索，而不是接口字节级兼容：

1. 输入关键词（可中文、可空格、可错别字场景后续再增强）。  
2. 可选：**输入即建议**（联想词条标题）。  
3. 提交后得到：**相关词条列表**（标题、摘要、可选缩略图、跳转 id）。  
4. 点进词条详情（详情页可二期，但搜索契约要预留 `lemma_id` / slug）。

首页上的「热搜词」本质是搜索的**导流入口**：点热词 = 带着预设 query 走同一套搜索。

### 4.2 为什么后端用 FastAPI

- 异步 IO 与本仓库协议一致（async 路由、异步 DB/Redis 客户端 + 池）。  
- 搜索场景天然适合：请求短、并发高、可加缓存。  
- 易与 Vue3 通过 JSON API / OpenAPI 协作。

### 4.3 搜索等价的层次（由浅到深）

| 层次 | 能力 | 本期建议 |
| --- | --- | --- |
| L1 | 标题精确/前缀匹配 | **必做** |
| L2 | 摘要关键字、简单相关排序 | **必做** |
| L3 | 拼音/纠错/同义词 | 可二期 |
| L4 | 个性化、向量语义检索 | 可三期 |

本期「等价搜索」验收应落在 **L1+L2 可用、接口稳定、可观测**，而不是一上来向量检索。

## 5. 需求二：首页数据同步（背景）

### 5.1 「同步」在本项目里的含义

推荐默认定义（若你意图不同，开工前再确认）：

> **把各首页模块所需的数据，从「权威数据源」刷新到「服务可读存储」（MySQL/Redis/对象存储），供 Vue3 首页聚合展示。**

权威数据源可以是：

- 自建运营后台 / YAML·JSON CMS（推荐起步）；  
- 定时任务生成的静态文件；  
- （仅在合规允许时）外部合作数据源。

### 5.2 为什么要单独做「同步」而不是页面里现算

- 首页模块多，现算会拖慢首屏、压垮 DB。  
- 热搜/动态刷新频率高，统计与专题频率低，**TTL 不同**，必须分任务。  
- 符合协议：Worker 用 `mq.sh` / 定时任务与 API `run.sh` 分离。

### 5.3 建议的同步边界（与对照模块对齐）

| 同步任务 | 写入什么 | 刷新节奏（建议起步） |
| --- | --- | --- |
| `sync_statistic` | 平台计数 | 5–15 分钟 |
| `sync_hot_lemmas` | 热搜词条列表 | 1–5 分钟或运营触发 |
| `sync_home_modules` | 热点/知识/特色等运营块 | 运营发布时或 10–30 分钟 |
| `sync_history_today` | 历史上的今天 | 每日或按日预热 |
| `sync_user_dynamic` | 用户动态（可选） | 近实时 / 分钟级 |

前端首页只读 **聚合 API**（FastAPI BFF），不直连多个原始源。

## 6. 技术选型背景（Vue3 + FastAPI）

| 层 | 选型 | 背景理由 |
| --- | --- | --- |
| 前端 | Vue3 | 组件化搭首页模块墙、搜索框与结果页；生态成熟 |
| 后端 | FastAPI | 异步 API、自动 OpenAPI、适合 BFF + Worker |
| 存储 | MySQL + Redis（协议要求池化异步） | 词条/运营落 MySQL；热搜与首页聚合缓存走 Redis |
| 运行 | 服务目录 `run.sh`；若队列 Worker 则 `mq.sh` | 符合 `AGENTS.md` |
| Python 环境 | workspace conda | 符合 `AGENTS.md` |

## 7. 明确非目标（避免范围膨胀）

本期开发背景默认**不做**：

- 完整词条编辑器 / 审核工作流（可预留表结构）  
- 登录体系统一（可只留匿名浏览 + 搜索）  
- 广告、风控对抗、第三方登录拷贝  
- 未经授权的全站正文镜像爬取  
- 像素级复刻百度百科视觉

---

## 8. 风险与约束

1. **合规**：外部站点内容与接口受版权与服务条款约束；自建数据优先。  
2. **接口易变**：对照站 XHR 路径仅作模块参考，不能当稳定依赖。  
3. **性能**：首页多模块必须缓存；搜索要限流与超时。  
4. **协议**：所有服务须满足异步 IO、日志可观测、错误码封装、plans 流程等。
