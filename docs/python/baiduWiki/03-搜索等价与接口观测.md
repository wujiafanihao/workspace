# 搜索等价与接口观测（js-reverse）

> 观测日期：2026-09-19  
> 工具：js-reverse-mcp  
> 对照：`/search?word=` 结果页 + `GET /lemma/api/search`

---

## 1. 用户侧搜索形态（等价要对齐的体验）

首页/内页搜索条：

- 输入框 class：`searchInput`
- 动作：「进入词条」「全站搜索」
- 热搜词可一键带入 query

结果页文案形态：

- 「百度百科为您找到相关词条约 N 个」
- 每条：标题（可高亮）、一句话描述、摘要、可选目录锚点、可选配图/视频
- 空结果：引导创建词条 / 反馈缺失 / 去网页搜索
- 旁路：广告卡（自建可忽略）

词条 URL 形态：`/item/{title}/{lemmaId}`（title URL 编码）

## 2. 观测到的搜索 API

**主接口**：`GET https://baike.baidu.com/lemma/api/search?word={keyword}`

### 2.1 请求侧注意点

- 浏览器会带 `x-bk-token` 等头；无有效 token 时 curl 常见：`{"code":10003,"msg":"token is invalid"}`
- 部分词可能命中风控：`{"code":1001,"msg":"命中敏感词", ...}`（观测样例词触发过；自建需自有敏感词策略，勿照搬对方规则）

### 2.2 成功响应（`code=0`，词「苹果」）

`data` 字段：

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| `word` | string | 查询词 |
| `total` | int | 命中总数 |
| `pn` | int | 页码 |
| `rn` | int | 每页条数（观测 50） |
| `query` | object | 查询结构 |
| `list` | array | 结果列表 |
| `lemmaId` / `lemmaTitle` | | 顶层可能为空（列表内才有） |
| `adList` | object | 广告（自建忽略） |
| `isPoliticalSensitive` | bool | 敏感标记 |
| `rsse` / `resFrom` | | 观测保留字段 |

### 2.3 `list[]` 单条字段（等价搜索核心契约）

| 字段 | 类型 | 自建是否要对齐 |
| --- | --- | --- |
| `lemmaId` | int | **要**（主键） |
| `lemmaTitle` | string | **要**（可含 `<em>` 高亮，前端需安全渲染/去标） |
| `lemmaDesc` | string | **要**（短描述） |
| `abstract` | string | **要**（摘要，可含 `<em>`） |
| `url` | string | **要**（相对路径即可） |
| `time` | string | 可选（更新时间） |
| `abstractImg` / `abstractImgSrc` | string | 可选 |
| `catalog[]` | `{txt,url}` | 可选（目录快捷跳转） |
| `video` | object | 可选 |
| `basicWeight` | number | 可选（排序权重参考） |

### 2.4 相关接口（非本期核心）

| 接口 | 作用 |
| --- | --- |
| `GET /lemma/api/guesslike?...` | 猜你喜欢 |
| 词条页一堆 `lemmaId=` 附属接口 | 详情增强（贡献者、收藏、视频列表等） |

详情页 URL 例：`/item/长征十二号/64095266` —— 说明 **ID 路由** 与搜索列表一致。

## 3. 「等价搜索」对本项目的定义（验收）

在 **自有词条库** 上实现，体验对齐上表，而不是复用百度 token/接口。

### 必做（P0）

1. `GET /api/search?word=&pn=&rn=`（FastAPI async）  
2. 返回：`total` + `list[{lemmaId, lemmaTitle, lemmaDesc, abstract, url}]`  
3. 标题前缀/包含匹配 + 简单相关排序（标题命中 > 描述命中）  
4. 摘要/标题高亮策略（服务端加 mark 或前端标，防 XSS）  
5. 空结果友好文案  
6. 超时、错误码、日志可观测（符合 `AGENTS.md`）  
7. 配对测试文件

### 应做（P1）

- 输入联想：`GET /api/search/suggest?q=`（标题前缀 topK）  
- Redis 缓存热点 query  
- 热搜点击 = 预填 word 调同一搜索

### 可后做（P2）

- 拼音/纠错/同义词  
- 向量语义检索

---

## 5. 从观测得到的工程教训

1. **搜索与词条详情是两条链路**：热搜 CDN 有词，不代表 search API 一定返回（风控/token/策略会导致空或错误码）。自建应用自己的可用性 SLA。  
2. **BFF 不要依赖对方 `x-bk-token`**。  
3. 列表项同时带 `lemmaId` + 可读 URL，前端跳转更稳。  
4. `catalog`/`video` 可渐进增强，勿阻塞 P0。
