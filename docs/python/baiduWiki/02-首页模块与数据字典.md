# 首页模块与数据字典（js-reverse 观测）

> 观测日期：2026-09-19  
> 工具：js-reverse-mcp（有头 Chrome）  
> 页面：`https://baike.baidu.com/`  
> 目的：为我们的 **Vue3 首页 + FastAPI 同步任务** 提供模块拆分与字段参考。  
> **不是**授权抓取说明书；自建产品应映射为自有 CMS/DB 字段。

---

## 1. 首页数据源总览

| 观测来源 | 类型 | 用途 |
| --- | --- | --- |
| `GET /lemma/api/home/module` | 动态 API | 首页主模块聚合 |
| `GET /lemma/api/home/statistic` | 动态 API | 全站统计数字 |
| `GET /lemma/api/home/dynamic` | 动态 API | 用户动态流 |
| `GET .../cms/home/hotLemmas.json` | CDN JSON | 热搜词条（today/yesterday） |
| `GET .../cms/home/eventsOnHistory/MM.json` | CDN JSON | 历史上的今天（按月） |
| `GET .../cms/pc_index/knowledge_topic_menu.json` | CDN JSON | 知识专题菜单 |
| `GET /api/wikihome/userlemma` | 动态 API | 用户相关词条（登录态） |
| 广告/风控类 | 忽略 | 自建不实现 |

统一响应壳（多数 lemma API）：

```json
{ "code": 0, "msg": "success", "data": { } }
```

## 2. 统计 `statistic`

**接口**：`GET /lemma/api/home/statistic`

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| `totalLemma` | int | 词条数 |
| `totalLemmaTitle` | int | 词条标题数（观测并存） |
| `totalEditNum` | int | 编辑次数 |
| `totalEditUser` | int | 编写人数 |
| `totalSchool` | int | 覆盖高校数 |
| `totalCategory` | int | 分类数 |
| `totalOdpUser` | int | 观测字段（团队相关计数） |

**自建映射建议**：`home_statistic` 表/缓存键；同步任务 `sync_statistic`；Redis TTL 短。

## 3. 主模块 `module`

**接口**：`GET /lemma/api/home/module`  
`data` 顶层键：`characteristics` / `hotLemma` / `hotspot` / `knowledge` / `photoBaike` / `userCard` / `style`

### 3.1 `characteristics[]` 特色入口

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| `title` | string | 入口标题 |
| `url` | string | 跳转链接 |
| `desc` | string | 描述（可含 `<br/>`） |
| `src` | string | 图片资源 id/hash |

### 3.2 `hotLemma` 热搜

观测：数组长度为 2（常对应今天/昨天两组；CDN `hotLemmas.json` 更明确拆成 `today`/`yesterday`）。

词条项字段：

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| `title` | string | 词条名 |
| `lemmaId` | int | 词条 ID |
| `lemmaDesc` | string | 短描述 |
| `abstract` | string | 摘要 |
| `wapAbstract` | string | 短摘要 |
| `link` / `url` | string | 词条 URL |
| `trend` | string | 如 `up` |

CDN `hotLemmas.json`：

```text
{ "today": [ {...} ], "yesterday": [ {...} ] }
```

项内常有 `lemmaInfo: { title, link, lemmaDesc, lemmaId }`。

### 3.3 `hotspot[]` 热点卡片

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| `itemId` | int | 内容 ID |
| `title` | string | 标题 |
| `author` | string | 作者 |
| `abstract` | string | 摘要 |
| `url` | string | 跳转 |
| `src` / `wapSrc` | string | 配图资源 |

### 3.4 `knowledge[]` 知识块

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| `itemId` | int | ID |
| `title` | string | 主题 |
| `desc` | string | 描述 |
| `link` / `wapLink` | string | 跳转 |
| `pic` | string | 图 |
| `lemmas[]` | array | 关联词条 `{ title, url }` |

### 3.5 `photoBaike[]` 图解/富媒体

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| `itemId` | int | ID |
| `title` | string | 标题 |
| `link` | string | 相对/绝对路径 |
| `titleSrc` / `homePageSrc` / `contentSrc` | string | 多尺寸图资源 |

### 3.6 `userCard[]` 社区卡片

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| `title` | string | 如「百科校园」 |
| `subTitle` | string | 副标题 |
| `tags[]` | string | 标签文案 |
| `users[]` | array | `{ uk, id, name, avator }`（字段名观测为 avator） |

### 3.7 `style`

观测可为空对象；预留皮肤/实验配置。

## 4. 用户动态 `dynamic`

**接口**：`GET /lemma/api/home/dynamic`  
`data` 为数组，项：

| 字段 | 类型 | 含义 |
| --- | --- | --- |
| `uk` | string | 用户标识 |
| `displayName` | string | 展示名 |
| `type` | int | 动态类型（编辑词条/参与任务等） |
| `time` | int | 时间戳 |
| `info` | object | 类型相关载荷，如 `{ taskId, taskName }` 或词条信息 |

**自建**：`home_dynamic` 流；注意脱敏与频率限制。

## 5. 历史上的今天

**CDN**：`/cms/home/eventsOnHistory/{MM}.json`（如 `09.json`）

结构（观测）：

```text
{ "09": { "0930": [ { year, title, festival, link, type, desc }, ... ], ... } }
```

| 字段 | 含义 |
| --- | --- |
| `year` | 年份 |
| `title` | 事件标题（可含 HTML a） |
| `type` | 如 `birth` |
| `link` | 词条链接 |
| `desc` | 描述 HTML |
| `festival` | 节日（可空） |

**自建**：按 `MMDD` 存事件表；前端按「今天」取。

## 6. 知识专题菜单

**CDN**：`knowledge_topic_menu.json`  
项示例：`{ title, itemId(实为 URL), itemOrder }`

**自建**：导航配置表 / YAML。

## 7. 对 Vue3 首页的模块建议

| Vue 区块组件 | 数据键 | 同步任务 |
| --- | --- | --- |
| `HomeSearchBar` | 热搜 topN | `sync_hot_lemmas` |
| `HomeStatistic` | statistic | `sync_statistic` |
| `HomeHotspot` | hotspot | `sync_home_modules` |
| `HomeKnowledge` | knowledge | 同上 |
| `HomeCharacteristics` | characteristics | 同上 |
| `HomePhotoBaike` | photoBaike | 同上 |
| `HomeUserCards` | userCard | 同上 |
| `HomeDynamic` | dynamic | `sync_user_dynamic` |
| `HomeHistoryToday` | eventsOnHistory | `sync_history_today` |
| `HomeTopicMenu` | menu | 可并入 modules |

FastAPI 提供：

- `GET /api/home/aggregate`：读缓存拼装上述块  
- 或分模块 `GET /api/home/{module}`
